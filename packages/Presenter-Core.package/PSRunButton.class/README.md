A PSRunButton is a small Button in the top right corner of a PSCodeMorph that allows the user to execute code inside a CodeField (without using ctrl + d).

Instance Variables
	action:		<Object>
	fontSize:		<Integer>
	hovered:		<Boolean>

action
	- the action (executeCode) that is supposed to be performed on click

fontSize
	- used to keep the size of the button and run symbol (>) in it relative to its PSCodeMorph

hovered
	- tracks if the button is hovered to change its color
