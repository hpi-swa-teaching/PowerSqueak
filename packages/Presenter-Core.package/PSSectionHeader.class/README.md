A PSSectionHeader is a header morph shown above the first slide of a section in the miniature sidebar. It is indented by its section level and shows a disclosure triangle, a coloured bar, the section name and its slide count. Clicking toggles collapse; the yellow button opens a context menu to rename, delete, indent or outdent the section.

Instance Variables
	section		the section this header belongs to (a PSSlideSection)
	tool		the PSPresentationTool that owns the sidebar (a PSPresentationTool)
