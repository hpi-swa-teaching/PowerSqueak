A PSSectionHeader is a header morph shown in the miniature sidebar. It appears right above the first slide of a section and draws itself: it is indented by its section level, shows a disclosure triangle, a coloured background bar and the section name together with the number of slides in the section. Clicking the header collapses or expands the section, and the yellow button opens a context menu for renaming, deleting, indenting and outdenting the section.

Instance Variables
	section		the section this header belongs to (a PSSlideSection)
	tool		the PSPresentationTool that owns the sidebar (a PSPresentationTool)
