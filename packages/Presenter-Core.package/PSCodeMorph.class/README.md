A PSCodeMorph is a TextMorph for PowerSqueak, that allows the user to write smalltalk code with syntax hightlighting. In combination with the PSRunButton it shows the output of a code snippet.

Instance Variables
	resultText:					<String>
	resultWasShowing:		<Boolean>
	runButton:					<PSRunButton>

resultText
	- the output of the code that was executed

resultWasShowing
	- to check whether a result partition should be shown

runButton
	- the instance of the PSRunButton for itself
