A PSContentLocation stores the position of a content container on a slide for undo and redo.

Instance Variables
	index:			<Integer>
	layoutFrame:	<LayoutFrame>
	slide:			<PSSlide>

index
	- The index of the content container in the slide's submorph list

layoutFrame
	- The layout frame describing the content container's position and size on the slide

slide
	- The slide that contains the content container
